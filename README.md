# Solar-System-Simulation-

An immersive 3D solar system simulation developed in Unity, designed to bring the mechanics of our solar system to life through realistic orbital motion, accurate relative scaling, and free-roam interactive exploration. The project was built as a **collaborative team effort**, with each team member responsible for researching, modeling, and programming the behavior of a specific planet — combining individual contributions into one unified, interactive simulation.

The goal of the project was not just to visualize the solar system, but to simulate its underlying physical logic: orbital paths, rotational speeds, relative sizing, and spatial distances — turning abstract astronomical concepts into something explorable and intuitive.

##  My Contribution — Jupiter Module
As part of the development team, I was responsible for the end-to-end development of the **Jupiter** module, including:
- Researching Jupiter's real orbital period, rotational speed, and relative size compared to Earth and other planets
- Integrating and scaling Jupiter's 3D model to remain visually consistent with the rest of the simulation
- Implementing Jupiter's orbital motion around the sun and its axial rotation using Unity's transform and physics systems
- Testing and fine-tuning Jupiter's motion to ensure smooth, realistic behavior within the shared scene
- Collaborating with teammates to merge individual planet modules into a single cohesive Unity scene without conflicts

##  Features
- Physically-inspired orbital and rotational motion for all planets around the sun
- Free interactive camera controls for exploring the scene from any angle and distance
- Scaled representation of planetary sizes and orbital distances for a realistic sense of scale
- Modular structure where each planet was developed and integrated as an independent component
- Clean, immersive 3D environment designed for an intuitive learning experience
- Smooth performance suitable for educational and exploratory use

##  What I Learned

## Built With
- **Unity** (C#)
- Unity's built-in physics and transform systems for motion and rotation
- Custom 3D assets and materials for planetary bodies

##  Project Structure
- `Assets/` — scripts, 3D models, materials, and scenes for all planets
- `ProjectSettings/` — Unity project configuration
- `Packages/` — Unity package dependencies

##  How to Run
1. Clone or download this repository
2. Open the project folder in **Unity Hub** (recommended Unity version: 2021 LTS or later)
3. Open the main scene from `Assets/Scenes/`
4. Press **Play** in the Unity Editor to explore the simulation
